# FitLean Tracker / 减脂助手 小程序版

这是当前项目的 Taro 微信小程序 MVP，位于仓库的 `miniprogram/` 目录。它迁移了核心记录和推荐能力，数据保存在微信小程序本地 storage 中，不使用云开发、后端服务或付费 API。

## 已实现功能

- 首页 Dashboard：今日摄入、运动消耗、净摄入、建议摄入、BMI、目标差距、今日建议。
- 个人资料：年龄、性别估算选项、身高、当前体重、目标体重、目标日期、活动水平、围度、饮食偏好、运动偏好、伤病备注。
- 饮食记录：内置 30 个常见食物，按克数自动估算热量和三大营养素，支持按日期查看和删除。
- 运动记录：内置 MET 表，按体重和时长估算消耗，支持按日期查看和删除。
- 进度记录：体重、腰围、BMI、变化趋势摘要。
- 推荐页：每日热量和宏量建议、食谱推荐、一周运动计划。
- 示例数据：首页可加载示例数据，方便本地预览。

## 安装

```bash
cd miniprogram
npm install
```

## 构建微信小程序

```bash
npm run build:weapp
```

构建产物输出到：

```text
miniprogram/dist
```

## 开发模式

```bash
npm run dev:weapp
```

## 微信开发者工具预览

1. 打开微信开发者工具。
2. 选择「导入项目」。
3. 项目目录选择仓库内的 `miniprogram/`。
4. AppID 可先使用测试号或在 `project.config.json` 中替换为你的真实小程序 AppID。
5. 微信开发者工具会读取 `project.config.json`，小程序根目录为 `dist/`。

## 数据说明

小程序版使用 `Taro.setStorageSync` / `Taro.getStorageSync` 保存数据。卸载小程序、清除缓存或换设备会导致数据不可见。正式发布前建议补充云同步或导出能力。
