# FitLean Tracker / 减脂助手 小程序版

这是当前 Web MVP 的 Taro + React + TypeScript 微信小程序版本，放在 `miniprogram/` 子目录中。它复用了核心类型、计算逻辑、食物库、运动 MET 表和食谱规则，使用微信小程序本地存储保存数据。

## 运行

```bash
cd miniprogram
npm install
npm run build:weapp
```

然后用微信开发者工具打开 `miniprogram/` 目录，编译产物在 `miniprogram/dist`。

开发监听：

```bash
npm run dev:weapp
```

## 功能范围

- 首页 Dashboard：今日摄入、运动消耗、净摄入、建议摄入、BMI、目标差距和今日建议。
- 个人资料：基础信息、目标、活动水平、偏好和伤病备注。
- 饮食记录：内置食物库，按克数估算热量和三大营养素。
- 运动记录：内置 MET 表，按体重和时长估算消耗。
- 进度记录：记录体重和围度，展示变化。
- 推荐页：宏量建议、食谱推荐和一周运动计划。
- 数据管理：示例数据、导出 JSON、导入 JSON、清空数据。

## 说明

所有数据保存在小程序本地存储中，不接入后端、不登录、不调用外部 AI 或食品数据库。

本应用提供的热量、运动消耗、食谱和运动建议均为估算，仅用于自我记录和一般健康管理，不构成医疗建议。
